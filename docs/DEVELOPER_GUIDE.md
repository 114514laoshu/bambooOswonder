## Architecture Overview / 架构概述

Bamboo OS is a monolithic kernel operating system for x86-64, written entirely in Python as a code generator that produces machine code.

Bamboo OS 是一个面向 x86-64 的单体内核操作系统，完全用 Python 编写，作为生成机器码的代码生成器。

### High-Level Architecture / 高层架构

```
+---------------------------------------------------+
|                   User Space                      |
|  +---------+  +---------+  +-------------------+  |
|  |  Apps   |  |  Libs   |  |  Dynamic Linker  |  |
|  +---------+  +---------+  +-------------------+  |
+---------------------------------------------------+
|                   System Call Interface           |
+---------------------------------------------------+
|                   Kernel Space                    |
|  +-------+ +-------+ +-------+ +-------+ +-----+  |
|  |  VFS  | |  TCP  | |  GUI  | | Sched | | IPC |  |
|  +-------+ +-------+ +-------+ +-------+ +-----+  |
|  +-------+ +-------+ +-------+ +-------+         |
|  |  MM   | |  FS   | |  Net  | | Drivers        |
|  +-------+ +-------+ +-------+ +-------+         |
|  +-------------------------------------------+   |
|  |              Hardware Abstraction          |   |
|  +-------------------------------------------+   |
+---------------------------------------------------+
|                   Hardware                        |
+---------------------------------------------------+
```

### Code Generation Approach / 代码生成方法

Unlike traditional OS development where you write C/assembly and compile it, Bamboo OS uses a Python-based code generator that directly emits x86-64 machine code.

与传统的操作系统开发（编写 C/汇编然后编译）不同，Bamboo OS 使用基于 Python 的代码生成器直接发射 x86-64 机器码。

**Advantages / 优势:**
- No cross-compiler needed / 不需要交叉编译器
- Full control over generated code / 完全控制生成的代码
- Easy to experiment / 易于实验
- Python tooling and ecosystem / Python 工具和生态系统

**Components / 组件:**
- `X64Assembler` - Instruction emitter / 指令发射器
- `KernelGenerator` - Kernel code generator / 内核代码生成器
- `BPPPackager` - Application packager / 应用打包器

## Kernel Architecture / 内核架构

### Boot Sequence / 启动序列

1. **Multiboot2 Header** - GRUB finds and loads kernel / GRUB 查找并加载内核
2. **32-bit Startup Stub** - Initial setup in protected mode / 保护模式初始设置
3. **Long Mode Switch** - Enable 64-bit mode / 启用 64 位模式
4. **Page Table Setup** - Build initial page tables / 构建初始页表
5. **GDT/IDT Setup** - Set up descriptor tables / 设置描述符表
6. **kmain** - Kernel main function / 内核主函数

### Kernel Entry Point / 内核入口点

The kernel entry point is generated by `create_kmain()` in the kernel generator.

内核入口点由内核生成器中的 `create_kmain()` 生成。

## Memory Management / 内存管理

### Physical Memory Manager (PMM) / 物理内存管理器

Bamboo OS uses a buddy system for physical memory allocation.

Bamboo OS 使用伙伴系统进行物理内存分配。

**Features / 特性:**
- Buddy system allocator / 伙伴系统分配器
- Bitmap allocator (fallback) / 位图分配器（备用）
- Memory statistics / 内存统计
- Debugging support / 调试支持

**Data Structures / 数据结构:**
- Free area array / 空闲区数组
- Bitmap for page tracking / 页面跟踪位图
- Page flags (used, reserved, etc.) / 页面标志（已用、保留等）

### Virtual Memory Manager (VMM) / 虚拟内存管理器

4-level page tables with support for:

4 级页表，支持：

- Identity mapping / 恒等映射
- Higher-half kernel / 高半核
- Copy-on-Write (COW) / 写时复制
- Memory protection / 内存保护
- User space isolation / 用户空间隔离

**Page Table Levels / 页表级别:**
- PML4 (Page Map Level 4) / 页映射第4级
- PDPT (Page Directory Pointer Table) / 页目录指针表
- PD (Page Directory) / 页目录
- PT (Page Table) / 页表

### Slab Allocator / Slab 分配器

Slab allocator for efficient small-object allocation.

用于高效小对象分配的 Slab 分配器。

**Caches / 缓存:**
- `kmalloc` general caches / kmalloc 通用缓存
- Object-specific caches / 对象特定缓存
- Emergency pools / 紧急池

**kmalloc sizes / kmalloc 大小:**
- 32, 64, 128, 256, 512, 1024, 2048, 4096 bytes

## Process Management / 进程管理

### Process Control Block (PCB) / 进程控制块

Each process is represented by a PCB structure.

每个进程由一个 PCB 结构表示。

**PCB Layout / PCB 布局:**
```
Offset  Size  Field
0       8     rax
8       8     rbx
...     ...   ... (all registers)
256     8     pid
264     8     state
272     8     priority
280     8     stack_ptr
288     8     page_table
...     ...   ...
```

### Scheduler / 调度器

CFS (Completely Fair Scheduler) inspired scheduler.

受 CFS（完全公平调度器）启发的调度器。

**Features / 特性:**
- Preemptive multitasking / 抢占式多任务
- Priority levels / 优先级
- Time slices / 时间片
- Round-robin within priority / 优先级内轮转

**States / 状态:**
- RUNNING - Currently executing / 当前执行
- READY - Ready to run / 准备运行
- BLOCKED - Waiting for event / 等待事件
- SLEEPING - Sleeping / 睡眠中
- ZOMBIE - Terminated but not reaped / 已终止但未回收

### Context Switching / 上下文切换

Context switch saves all registers and switches page tables.

上下文切换保存所有寄存器并切换页表。

```assembly
; Save current state / 保存当前状态
push rax
push rbx
...

; Switch stack / 切换栈
mov [current_rsp], rsp
mov rsp, [next_rsp]

; Switch page table / 切换页表
mov cr3, [next_cr3]

; Restore next state / 恢复下一个状态
pop ...
pop rbx
pop rax
iretq
```

## Adding System Calls / 添加系统调用

To add a new system call:

添加新的系统调用：

1. **Choose a syscall number / 选择系统调用号**
   ```python
   SYS_MYCALL = 200
   ```

2. **Implement the handler / 实现处理函数**
   ```python
   def create_sys_mycall(self):
       """Generate mycall syscall handler / 生成 mycall 系统调用处理函数"""
       c = self
       c.label("sys_mycall")
       # ... implementation ...
       c.ret()
   ```

3. **Add to syscall table / 添加到系统调用表**
   ```python
   syscall_table[SYS_MYCALL] = "sys_mycall"
   ```

4. **Add user-space wrapper / 添加用户空间包装**
   ```c
   int mycall(int arg) {
       return syscall(SYS_MYCALL, arg);
   }
   ```

## Adding Drivers / 添加驱动程序

To add a new device driver:

添加新的设备驱动程序：

1. **Create driver file / 创建驱动文件**
   ```
   kernel/drivers/mydevice.py
   ```

2. **Implement probe/init / 实现探测/初始化**
   ```python
   def mydevice_init():
       """Initialize device / 初始化设备"""
       # Probe for device / 探测设备
       # Initialize hardware / 初始化硬件
       # Register interrupt handler / 注册中断处理函数
       pass
   ```

3. **Register with driver manager / 向驱动管理器注册**
   ```python
   driver_manager.register("mydevice", mydevice_init)
   ```

4. **Add to build config / 添加到构建配置**
   ```python
   DRIVERS_CONFIG = {
       "mydevice": True,
       ...
   }
   ```

## Adding Applications / 添加应用程序

To add a new BPP application:

添加新的 BPP 应用：

1. **Create app directory / 创建应用目录**
   ```
   userland/apps/category/MyApp/
   ```

2. **Write application code / 编写应用代码**
   ```python
   # myapp.py
   def main():
       print("Hello from MyApp!")
       return 0
   ```

3. **Package as BPP / 打包为 BPP**
   ```python
   from toolchain.bamboo_pack import create_simple_bpp
   create_simple_bpp("MyApp", code, "MyApp.bpp", executable=True)
   ```

4. **Add to build config / 添加到构建配置**
   ```python
   APPS_CONFIG = {
       "include": [..., "MyApp"],
       ...
   }
   ```

## Debugging / 调试

### QEMU Debugging / QEMU 调试

**Using GDB / 使用 GDB:**

```bash
# Start QEMU with GDB server / 启动带 GDB 服务器的 QEMU
python scripts/run_qemu.py --target=wonder2 --debug

# In another terminal / 在另一个终端
gdb build/wonder2/wonder2.elf

(gdb) break kmain
```

### Serial Debugging / 串口调试

All kernel output goes to serial port by default.

所有内核输出默认通过串口输出。

```bash
# View serial output / 查看串口输出
python scripts/run_qemu.py --target=wonder2
```

Use `sys_debug_print` to print from kernel space:

使用 `sys_debug_print` 从内核空间打印：

```python
# In kernel code / 在内核代码中
c.mov_r64_imm(c.REG64["rdi"], debug_string)
c.call("debug_print")
```

## Code Style / 代码风格

### Bilingual Comments / 双语言注释

All code must have English + Chinese comments.

所有代码必须有英文+中文注释。

```python
# ============================================================================
# Module: example.py
# 模块：example.py
# Description: Example module
# 描述：示例模块
# ============================================================================

def example_function(arg):
    """
    Example function that does something.
    做某事的示例函数。

    Args:
        参数：
        arg (int): Description / 描述

    Returns:
        返回：
        bool: Result / 结果
    """
    return True
```

### Naming Conventions / 命名约定

- **Classes**: PascalCase (`MyClass`)
- **Functions**: snake_case (`my_function`)
- **Variables**: snake_case (`my_variable`)
- **Constants**: UPPER_SNAKE_CASE (`MY_CONSTANT`)
- **Private**: _prefix (`_private_method`)

### File Structure / 文件结构

Each file should have:

每个文件应该有：

1. File header with module info / 带模块信息的文件头
2. Imports / 导入
3. Constants / 常量
4. Classes / 类
5. Functions / 函数
6. Main entry point (if applicable) / 主入口点（如适用）
